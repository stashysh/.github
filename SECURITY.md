# Security policy

## Reporting a vulnerability

Please **do not** report security vulnerabilities in public issues, discussions, or pull requests.

Email **contact@stashy.sh** with:

- the affected repository and version
- a description of the issue and its impact
- steps to reproduce, or a proof of concept

We'll acknowledge your report within a few days and keep you updated until it's resolved. Once a fix is released, we're happy to credit you in the release notes.

## Supported versions

Security fixes are made in the latest release. Please upgrade to it before reporting.
